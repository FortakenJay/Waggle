## Status language

The wiki uses three labels:

- **Established** — Jih chose it or it is present in the repository.
- **Proposed** — useful direction that still needs Jih's decision.
- **Verified** — directly observed through a completed check; the check is named.

An implemented file is not automatically a verified workflow. Commands, screenshots, and external writes remain unverified until they actually run.
